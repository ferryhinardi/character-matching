## 🆘 Troubleshooting

**No sound?**
→ Check browser audio isn't muted
→ Press `P` → Settings → Enable sound

**Can't see my scores?**
→ Check browser allows localStorage
→ Try clearing site data and replaying

**Game runs slowly?**
→ Close other browser tabs
→ Try Classic version (index.html)
